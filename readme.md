Quick Start Guide
==========================
Create and activate a virtual environment for your project. This will help you manage dependencies and keep your project isolated from other Python projects on your system.
# macOS / Linux
python3 -m venv .venv
source .venv/bin/activate

# Windows (Command Prompt / PowerShell)
python -m venv .venv
.venv\Scripts\activate

Install the required dependencies for your project. You can do this by running the following command in your terminal:
pip install -r requirements.txt
